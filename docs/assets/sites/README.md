# Site logos

The README's table of supported job boards shows these two logos. The other sites' logos load from their owners' servers.

| Files | Source | Checked |
| --- | --- | --- |
| `linkedin-light.svg`, `linkedin-dark.svg` | The `linkedin-bug-blue-medium` logo that LinkedIn's website serves inline, in its blue `#0a66c2` and its white | 2026-11-10 |
| `indeed-light.svg`, `indeed-dark.svg` | The `indeed` icon of [Simple Icons](https://simpleicons.org), in its blue `#003a9b` and in white | 2026-11-10 |

Each `light` file is for a light background and each `dark` file for a dark one.
